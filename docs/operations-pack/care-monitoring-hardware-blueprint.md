# Care Monitoring Hardware Blueprint

## Goal
Deploy a practical, privacy-conscious caregiver monitoring stack for watch-based safety alerts, camera-driven occupancy awareness, and optional wearable vital checks.

## Design Principles
1. Local-first processing for privacy and low latency.
2. Redundant alerting for high-severity events.
3. Simple installation and maintenance path.
4. Device-agnostic architecture to avoid lock-in.
5. Start with a conservative workflow that is useful even before the AI gets fancy.

## Recommended Hardware Layers

### 1. Watch and Mobile Layer (Primary Alert Signal)
- One smartwatch or fitness band with:
  - heart rate
  - blood oxygen (SpO2)
  - fall detection if available
  - mobile alert export or local bridge
- A phone or tablet can act as the caregiver bridge if direct watch integration is limited.

Good first options to evaluate:
- Apple Watch SE 2 or a recent Apple Watch if budget allows
- Samsung Galaxy Watch 6/7 for Android-friendly setups
- Garmin for battery life and basic health tracking

### 2. Camera Layer (Context and Fallback Signal)
- 2 indoor cameras with:
  - person detection or motion detection
  - night vision
  - RTSP or ONVIF support
- 1 door-facing camera for entry/exit events.
- Optional: one outdoor camera for perimeter awareness.

Examples to evaluate:
- Reolink PoE/Wi-Fi models (RTSP support)
- Tapo or similar budget-friendly RTSP-capable cameras
- UniFi Protect cameras for a more polished local ecosystem

### 3. Home Automation Hub
- Dedicated always-on hub for event routing:
  - Mini PC (already available) or
  - Home Assistant Green class device

Software stack:
- Home Assistant or Node-RED
- MQTT broker (Mosquitto)
- AI Hub scripts for policy and triage

### 4. Reliability and Safety Layer
- UPS battery backup for hub + router + key camera.
- Dual network options if possible (wired + fallback Wi-Fi).
- Optional LTE backup for outage alerts.

### 5. Alerting Layer
- Two-tier notifications:
  - Tier 1: caregiver mobile push
  - Tier 2: SMS / backup contact escalation
- Logged incident timeline for review.

## Minimum Viable Setup (Fast Start)
1. Use one smartwatch plus one living-area camera and one door camera.
2. Add a simple local alert flow for fall detection, inactivity, missed check-ins, and door activity at night.
3. Configure trigger simulation via tools/run-care-alert-simulation.ps1.
4. Validate alerts for door activity, inactivity, and low oxygen conditions.
5. Tune thresholds weekly.

## Recommended First-Release Rules
1. Fall detection triggers immediate caregiver alert.
2. 90+ minutes of inactivity prompts a caregiver check-in.
3. Missed check-ins trigger a follow-up prompt.
4. Door activity at night creates a safety timeline entry.
5. Low SpO2 or abnormal heart-rate trends produce a caution alert.

## Expansion Path
1. Add medication reminders and check-in prompts.
2. Add geofencing and zone-based movement alerts.
3. Add utility monitoring (power outages, smart plugs).
4. Add clinician-friendly weekly summary export.

## Ethics and Consent
- Monitoring should be consent-based whenever possible.
- Keep retention windows minimal.
- Restrict access to caregiver-approved accounts.
- Treat all vitals alerts as support signals, not medical diagnosis.
- Keep the system explainable and conservative for caregiver use.

## Budget Guidance
- Practical starter bundle: one watch + one living-area camera + one door camera + local hub = roughly $300 to $500 depending on whether you buy new or refurbished.
- If the watch is the top budget item, the first release can still work with a single camera and a phone-based bridge.
- If the watch is not available immediately, start with one camera and the inactivity/door-event rules first.
