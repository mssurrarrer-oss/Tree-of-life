# Prompt Pack

## Prompt P1: Claim extraction
Extract atomic claims from the source text. Return only claims that can be tested.

## Prompt P2: Counterexample search
Given one claim, produce plausible counterexamples and boundary conditions.

## Prompt P3: Cross-domain impact map
Given one claim, map likely impacts to language, scientific terminology, medical terminology, and religious interpretation.

## Prompt P4: Evidence-to-report synthesis
Generate a report section from evidence records only. Do not introduce new claims.

## Prompt P5: Risk audit
List failure modes, ambiguity risks, and mitigation checks for the current claim set.
