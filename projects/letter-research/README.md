# Letter Research Project

This project captures testable logic for letter-level interpretation and builds durable evidence for cross-model analysis.

## Core artifacts
- scope-map.md: boundaries, impacted domains, benefits, risks
- logs/daily-logic-log.md: one factual logic entry per day
- templates/letter-claim-template.md: standard claim structure per letter
- templates/evidence-record-template.md: citation and provenance format
- report-spec.md: structure for audience-ready reports

## Daily protocol
1. Add one factual claim to logs/daily-logic-log.md.
2. Expand into a letter claim file using templates/letter-claim-template.md.
3. Attach sources and confidence level using templates/evidence-record-template.md.
4. Run ingest to keep retrieval current.

## Publication protocol
1. Build a neutral technical report and a narrative report from the same evidence base.
2. Include model/software provenance for every generated section.
3. Mark each claim as confirmed, provisional, or under review.
