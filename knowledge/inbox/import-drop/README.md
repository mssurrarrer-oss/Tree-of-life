# Conversation Import Drop Folder

Drop exported conversation files here for automatic routing during daily check-in.

Supported file types:
- .md
- .txt
- .json
- .docx
- .xlsx

Routing behavior (default):
- Items are moved to knowledge/inbox/group/conversations/ unless filename hints personal/private.
- A metadata note is created next to each routed file.

Examples:
- 2026-07-28-copilot-history.md
- google-gemini-notes.docx
- private-chatgpt-reflection.txt
